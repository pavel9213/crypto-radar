# Known limitations

- Feed autodiscovery cannot guarantee that every project exposes RSS or Atom.
- The Google News RSS endpoint is a secondary discovery channel and may include stale, duplicate, or loosely related articles.
- Keyword-based category and rumor detection can miss context or produce false positives.
- An official account can share an unverified claim; the Confirmed label describes source origin, not independent fact-checking.
- X API access and rate limits depend on the account's current API plan and permissions.
- Static browser storage is local to one browser profile and is not synchronized across devices.
- URL validation confirms the URL shape, not the safety or truthfulness of the destination.
- The collector does not provide investment advice or guarantee the timing of TGE, snapshots, or airdrops.

These limitations should be revisited when adding new source types or changing confidence-label semantics.
