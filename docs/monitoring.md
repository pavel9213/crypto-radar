# Operational monitoring

After a scheduled collection run, review these signals:

- Did the workflow finish successfully?
- Did the item count change sharply compared with recent runs?
- Are the newest entries dated plausibly and linked to real publishers?
- Did validation pass?
- Was the digest regenerated alongside the feed?
- Did an upstream source start returning errors or a different content type?

A successful workflow only proves that its steps completed. It does not guarantee relevance, completeness, or factual accuracy of every item.
