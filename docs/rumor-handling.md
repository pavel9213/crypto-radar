# Rumor handling

Crypto Radar uses keyword heuristics to flag wording such as rumor, leaked, allegedly, or speculation. These signals are imperfect and can miss euphemisms or flag an article that is merely discussing rumors.

## Editorial rules

1. A rumor label means the text appears speculative; it does not prove the claim is false.
2. An official source can still publish an unconfirmed plan or estimate.
3. Secondary reporting should not be upgraded to official confirmation simply because several sites repeat it.
4. Preserve the original source link and publication date when available.
5. For high-impact TGE or snapshot claims, check the project's own announcement before acting.

When improving detection, test both the phrase being added and a counterexample that should not be flagged.
