# Signal categories and confidence labels

Crypto Radar separates the topic of an item from the confidence assigned to its source.

## Categories

- **TGE** — token generation events, token launches, and listing-date announcements.
- **Snapshot** — snapshot notices, eligibility checks, and snapshot checkers.
- **Airdrop** — claim windows and airdrop announcements.
- **Points** — points programs, XP, and leaderboards.
- **Partnership** — partnerships, collaborations, and integrations.
- **News** — items that do not match a more specific category.

Classification is keyword-based. Review unusual headlines manually because a phrase can be ambiguous or used in a different context.

## Confidence labels

- **Confirmed** — collected from a configured official project domain or configured official account. This indicates source origin, not independent verification of every claim.
- **Unconfirmed** — collected from secondary coverage; confirm it using a primary source.
- **Rumor** — wording associated with speculation or leaks was detected. Treat it as unconfirmed regardless of where it appeared.
- **Monitoring** — a manually tracked item that has not yet been verified.

## Good practice

Always open the source link before acting on a TGE date, snapshot, or airdrop claim. Automated labels are triage aids, not investment advice or guarantees of authenticity.
